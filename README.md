# 🐾 Pet Shop Website

This project is a **static Pet Shop website** built using **HTML and CSS**. It simulates a simple online pet store where users can browse pets, view prices, place an order, and see an order confirmation page.

This is a **front‑end only project** — no backend, database, or real payment integration.

---

## 🚀 Features

- ✅ Welcome / Landing page
- ✅ Pet listing page with images & prices
- ✅ Add to Cart → redirects to order page
- ✅ Order form (customer details)
- ✅ Order confirmation page
- ✅ Clean UI with hover effects & animations
- ✅ Embedded Google Maps location

---

## 🛠️ Technologies Used

- **HTML5** – page structure
- **CSS3** – styling, animations, layout
- **JavaScript (basic)** – page redirection using `onclick`

No frameworks. No libraries. Pure basics.

## ▶️ How to Run the Project

1. Download or clone the project
2. Open the folder
3. Double‑click **`index.html`**

OR

- Right‑click `index.html`
- Open with any modern browser (Chrome / Edge / Firefox)

No server required.

---

## 🧭 Page Flow

```
index.html  →  mini.html  →  sign.html  →  order.html
```

- **Get Started** → Pet list
- **Add to Cart** → Order form
- **Place Order** → Confirmation page
